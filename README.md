# Attribute-Controlled Face Generation and Multi-Label Classification with CelebA

A deep-learning pipeline combining a DenseNet169–BiLSTM classifier,
a conditional VAE, and a Streamlit interface for analyzing and
generating facial attributes from the CelebA dataset.

| Jiatong Peng    | Streamlit interface and model-selection functionality                                                                                                   |
